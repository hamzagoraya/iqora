# Xclean – Contact Us React Application

Modern, responsive React.js web application for **Xclean Cleaning Services**, converted from static template files into a clean React + Vanilla CSS project powered by Vite.

## Features
- **Modern React Components**: Header, Hero Banner, Contact Info Cards, Contact & Estimator Section, Global Office Location Switcher, Partner Logo Marquee, Newsletter Subscription, and Footer.
- **Interactive Cost Estimator**: Live price calculator based on square footage and service frequency.
- **Dark & Light Mode**: Built-in theme toggle with stored preference in `localStorage`.
- **Responsive Layout**: Custom Vanilla CSS design system with mobile navigation drawer.

## Available Scripts

In the project directory, you can run:

### `npm run dev`
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`
Builds the app for production to the `dist` folder.

### `npm run preview`
Locally previews the production build.
